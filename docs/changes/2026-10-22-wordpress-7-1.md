# Update WordPress to 7.1.3

- Date: 2026-10-22
- Branch: morrigan/update-php
- Commits: pending
- Area: infra | web
- Breaking: no

## Summary

WordPress core is updated from 6.9.10 to 7.1.3 (`roots/wordpress` in
`composer.json`). No theme or plugin code changes were needed.

## API changes

none

## Data model changes

WordPress core schema only (db version 60717 -> 61833). No custom tables
change.

## Migrations

none added. Each environment needs the WordPress database update once after
deploying:

```bash
wp core update-db
```

Until then, wp-admin shows the "database update required" screen. The front
end keeps working.

## Behaviour changes

- The block editor (posts and pages) always loads in an iframe since 7.1.
  The `rkg-gallery` block still registers, renders, saves as valid and opens
  the media library in the iframed editor.
- `excursion`, `course` and `rkg-post` do not set `show_in_rest`, so they
  keep using the classic editor and are not affected by the iframe change.
  Their meta boxes, the Leaflet map and the plugin JavaScript load without
  errors with jQuery UI 1.14.2.
- WordPress 7.0 adds a new default "Modern" admin colour scheme. The theme
  removes the colour scheme picker from profiles, so users cannot switch
  back.
- WordPress 7.1 list tables render the title cell as the row header (`th`)
  instead of the checkbox cell. No custom CSS or JS targets those cells.
